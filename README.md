## The six rules

1. Answer **every component** of the task, in the requested format, to the named audience.
2. Apply the **information on the day**. Unapplied research earns nothing.
3. Say **why**. Every point carries a *because*.
4. Respect the **scope**. "High level", "ignore tax", "no calculations", "only critique what is provided" are instructions.
5. **Conclude.** An analysis without a recommendation is an incomplete task.
6. Never use your real name.
